Vad en media query gör

Dra i fönstrets kant. Ingenting på den här sidan använder JavaScript för att ändra utseende. Allt du ser ändras av en enda regel längst ner i CSS-filen.

– px · – rem

Under 40rem. Bara basreglerna gäller. Media queryn finns i filen men gör ingenting just nu.

40rem och uppåt. Basreglerna gäller fortfarande, och media queryn läggs ovanpå dem.

Basen
.lankar li {
  display: block;
  margin-bottom: 0.4rem;
}

.kort {
  padding: 1rem;
}
Media queryn
@media (min-width: 40rem) {

  .lankar li {
    display: inline-block;
    margin: 0 1.25rem 0 0;
  }

  .kort {
    padding: 2rem;
  }

}

Lägg märke till tre saker. Media queryn tar aldrig bort något, den lägger till ovanpå. Basen är den smala layouten, inte den breda. Och brytpunkten ligger där just den här layouten slutar se bra ut, inte vid någon telefonmodells bredd.
