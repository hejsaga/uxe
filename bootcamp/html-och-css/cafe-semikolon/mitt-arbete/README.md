# Din mapp

Här jobbar du.

Varje gång du ska göra en övning: kopiera hela stegmappen hit in och öppna kopian.
Till exempel `steg-1-divsoppa` till `mitt-arbete/steg-1/`.

Stegmapparna ägs av kursen. Jag lägger till och rättar material under veckan,
och när du kör `git pull` skrivs de över. Allt du har här inne rörs aldrig.

Filer i den här mappen är bara dina.
